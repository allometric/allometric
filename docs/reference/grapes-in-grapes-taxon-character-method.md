Check if a Taxon contains a character

## Usage

```r

## S4 method for signature 'Taxon,character':
%in%(x, table)
```

## Arguments

- **x** — A `Taxon` object

- **table** — A character vector

## Value

TRUE or FALSE indicating if any of the Taxa fields appear in the character.
